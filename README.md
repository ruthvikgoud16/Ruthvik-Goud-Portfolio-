# Ruthvik Goud — AI & Hardware Portfolio

Interactive engineering portfolio for **Ruthvik Goud**: ECE at **Anurag University**, **AI Engineering Intern at Nimblize**, Data Analyst Intern at Bluestock Fintech, OnePlus Student Ambassador.

## Stack
- React 19 + TypeScript + Vite + Tailwind CSS 4
- Motion (Framer Motion) for viewport transforms
- Express + Gemini companion (`/api/chat`)
- Vercel-ready (`vercel.json`)

## Sections
- **Brief** — Anurag University ECE, builder bio
- **Engineering Lab** — PCB board: Pramāṇa, Nimblize intern stack, Aero Dot, Arduino, API rack
- **Work** — Featured: Pramāṇa (evidence-gated GraphRAG) and Nimblize (internship product)
- **Leadership** — OnePlus Ambassador, Unstop Campus Champion
- **Timeline** — Nimblize intern first, then Bluestock, then campus roles

## Local

```bash
npm install
npm run dev
```

Set `GEMINI_API_KEY` in `.env` for the chatbot (see `.env.example`).

Drop a PDF at `public/resume.pdf` (regenerate with `python3 public/generate-resume.py`) to power the Resume button.
